## 기술적 관점 / Engineering Focus

제가 관심을 두는 것은 특정 프레임워크 자체보다, **업무 시스템이 시간이 지나도 일관성과 변경 가능성을 유지하도록 만드는 방법**입니다.

My engineering focus is **keeping business systems consistent, traceable, and adaptable as they evolve**, beyond the choice of framework.

특히 다음과 같은 질문을 코드와 프로젝트를 통해 탐구하고 있습니다.

I explore the following questions through code and projects.

- 동일한 요청이 여러 번 들어와도 안전하게 처리할 수 있는가?  
  How can repeated requests be processed safely?

- 중간 실패가 발생했을 때 데이터의 정합성을 어떻게 보장할 것인가?  
  How can data integrity be preserved when a workflow fails partway through?

- 복잡하고 자주 변경되는 업무 규칙을 어떻게 코드와 데이터로 분리할 것인가?  
  How can complex, frequently changing business rules be separated from application code and modeled as data?

- 상태 변화와 이력을 어떻게 추적하고 재현할 것인가?  
  How can state transitions and their history be traced and reconstructed?

- 설계 의도를 테스트와 자동 검증으로 어떻게 지속적으로 보장할 것인가?  
  How can tests and automated verification continuously uphold design intent?
